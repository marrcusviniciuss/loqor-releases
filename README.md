# LOQ para Windows

Ditado por voz para Windows. Você fala, o texto aparece pronto no campo onde o cursor está. Funciona offline, em português e inglês. O nome vem do latim "loquor": eu falo. A coruja é a LOQuinho.

**Baixar a versão mais recente:** [LOQ-setup.exe](https://github.com/marrcusviniciuss/loqor-releases/releases/latest/download/LOQ-setup.exe)

Windows 10 e 11. O app avisa sozinho quando há uma versão nova e se atualiza em um clique.

Como o instalador ainda não tem certificado de assinatura de código, o Windows pode mostrar o aviso "O Windows protegeu o computador". Clique em "Mais informações" e depois em "Executar assim mesmo".
